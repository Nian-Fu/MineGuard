# ADR-021：多目标跟踪器

- 状态：Proposed / evidence blocked
- 日期：2026-08-22
- 决策范围：单摄像头人员轨迹、越线、入侵停留和区域计数

## 背景与决策

拟采用 ByteTrack 作为单摄像头默认跟踪候选，通过本项目的跟踪适配器输出统一 track ID、边界框与生命周期事件。业务规则不读取 ByteTrack 私有状态；跟踪器重置、空帧老化和 ID 回收属于强制契约。跨摄像头身份关联不由 ByteTrack 承担，Re-ID 必须另立数据与合规评审。

候选包括 ByteTrack、DeepSORT 类方案和 OC-SORT 类方案。当前选择依据是低分检测关联思路、较小的集成面及既有适配代码，并非现场精度结论。

## 后果

- RTSP 断流、outbox 背压跳到实时流或模型版本切换时必须重置轨迹和持续时间规则，不能跨不可观测窗口延续事件。
- 规则时间使用单调时钟，事件时间使用 UTC；线计数方向历史必须随轨迹回收。
- 生产参数必须按场景校准，不能把公开 MOT 数据集参数直接用于井下。

## 转为 Accepted 的证据

1. 固定源码 commit、许可证哈希、依赖锁、SBOM 与 CVE 结果。
2. 在矿井域序列报告 HOTA、IDF1、MOTA、ID switches、轨迹碎片和计数误差，并按遮挡、密度和照度分层。
3. 验证空检测、乱序/丢帧、断流重连、NTP 回拨、ID 复用和 24 小时内存稳定性。
4. 与至少一个独立跟踪基线在同一检测输出和同一序列上比较，并保存参数、种子和原始报告。
