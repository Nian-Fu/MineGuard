# ADR-024：强化学习研究框架

- 状态：Proposed / evidence blocked
- 日期：2026-08-22
- 决策范围：离线 GPU 资源调度研究，不包含生产自动控制批准

## 背景与决策

拟用 Gymnasium 定义可回放环境，以 Stable-Baselines3 PPO 作为首个序列决策候选，并与确定性启发式、随机策略和线性 contextual bandit 比较。PPO 只优化高危/普通流的帧步长、分辨率和共享批量；不可绕过的安全层在策略之后执行。当前生产默认仍是确定性调度，RL 不参与检测、人脸身份或入侵事实判定。

候选包括 contextual bandit、PPO、DQN 系列、SAC 和离线 RL。长期队列效应支持测试序列策略，但数据覆盖、奖励投机、训练方差和反序列化风险阻止直接上线。

## 后果

- 正式评估计划使用冻结 v3 trace 和独立开发种子；候选锁定前不得反复观察准入集。v3 逐种子绑定总步数、高危切片样本数、故障覆盖和 trace SHA-256。当前冻结常量尚未独立复现，协议保持 `unsealed` 并阻断所有准入。
- 高危召回任一种子不得低于启发式基线，配对 Student-t 下界不得低于零；延迟、队列、安全覆盖和故障回落同时阻断。
- SB3/PyTorch ZIP 按可执行输入隔离加载，只反序列化同一次受限读取中完成 SHA-256 验证的内存快照。
- 训练同时生成 manifest，绑定模型、训练/开发 trace、实际依赖版本和核心源码摘要；manifest 仍须由隔离流水线签名。
- contextual bandit 及去队列/去故障状态消融只提供研究证据，不参与 PPO 放行。

## 转为 Accepted 的证据

1. 固定框架 commit、许可证哈希、Python 哈希锁、训练容器 digest、SBOM、签名和 CVE 扫描。
2. 用目标 GPU 实测数据重新拟合环境，归档真实回放集版本、训练源码、五个以上独立训练种子、模型摘要与原始指标。
3. 完成启发式、随机、bandit、PPO、特征/奖励消融和独立封存集复核，禁止只报告最优种子。
4. 先运行至少 14 天只读影子；随后仅普通区域 5% 金丝雀，具备延迟、漏检代理、OOM、遥测陈旧和节点抖动自动回滚。
5. 高危区域控制需安全、生产、算法三方书面批准；在此之前本 ADR 即使研究框架获批，也不授权生产动作下发。
