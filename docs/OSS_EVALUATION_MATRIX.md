## 评分方法

每项 1-5 分：许可证清晰度 25%、维护成熟度 20%、矿井域适配 20%、部署性能 20%、可观测/可运维 15%。存在权重使用限制或强 copyleft 时，无论总分多少都不能直接进入闭源生产镜像。

## 初步组合

- 数据：Label Studio + DVC + S3 兼容对象存储；按摄像头/日期分组切分。
- 训练：MMDetection；人脸权重自训或采购明确商用授权模型。
- 部署：MMDeploy/TensorRT -> Triton；边缘高密度 NVIDIA 场景对照 DeepStream。
- 跟踪与规则：ByteTrack 输出统一轨迹，本仓库规则引擎完成脚点围栏、越线和聚集判定。
- 媒体：MediaMTX 提供 WebRTC/HLS，业务 API 不转发视频字节。
- 调度研究：Gymnasium + SB3 PPO；确定性安全层始终在策略输出之后执行。

## 联网复核证据模板

每个进入候选短名单的仓库必须归档：仓库 URL、完整 commit SHA、签名 tag、许可证文件 SHA-256、依赖锁、最近 12 个月提交/发布情况、未关闭安全 issue、OSV/NVD 扫描、镜像 SBOM、目标 GPU 基准结果、维护退出方案。任何一项缺失均标记“证据不足”，不能写入最终 ADR 的 Accepted 状态。
