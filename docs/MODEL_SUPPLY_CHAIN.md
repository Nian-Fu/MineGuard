# 模型供应链与生产准入

## 1. 信任链

生产模型不是一个可变文件名，而是以下不可变身份的组合：

```text
算法类型 + 模型版本 + 制品 SHA-256
       |            |
       |            +-- 本地模型文件逐字节校验
       +--------------- 中心 model_artifacts 唯一记录
                            |
                      独立管理员审批
                            |
                Triton artifact_sha256 配置核对
                            |
                    边缘心跳再次报告
```

`ModelArtifact` 同时记录运行时、SPDX 许可证标识、源码仓库、固定 commit 和离线指标。登记仅建立候选记录，不等同于部署或批准。

## 2. 审批与撤销

生产 Compose 默认启用：

- `MINEGUARD_ENFORCE_APPROVED_EDGE_MODELS=true`
- `MINEGUARD_REQUIRE_FOUR_EYES_MODEL_APPROVAL=true`

创建制品的管理员不能批准自己的制品。审批或撤销必须提交原因并写入审计日志；撤销后，仍报告该摘要的节点在下一次心跳变为 `degraded`，生产事件入口返回 409。撤销不会删除历史事件中的模型清单。

## 3. 边缘启动校验

edge 配置文件本身限制 `model_root` 与 manifest 都必须位于配置目录内，且 manifest 必须位于该 `model_root` 下；`ModelManifest.load()` 再限制制品路径必须位于 `model_root` 内，形成两层路径逃逸拒绝。edge worker 在连接视频前完成：

1. manifest JSON 严格类型、输入尺寸和类别表校验；数字字符串、对象到字符串等隐式转换一律拒绝；
2. 本地制品 SHA-256 全量计算；
3. Triton 模型配置 `parameters.artifact_sha256.string_value` 核对；
4. 每路摄像头独立 Triton 客户端的有界连接检查。

任何一步失败都让进程退出，由服务管理器按退避策略重启，不允许以未知模型继续推理。

Triton 单帧输出只接受至多 100,000 行的 `[N,6]` 或 `[1,N,6]`，并逐行拒绝非有限值、越界置信度、非整数/越界类别和无面积框。该上限是畸形响应的资源保护边界，不是正常检测容量目标；现场模型应远低于此值。

实时人脸 Provider 必须返回 `model_version + model_sha256`，登记模板的 AES-GCM 附加数据同时绑定这两个字段。生产准入开启时，登记、人工识别、edge 实时识别和结构化事件补报都会核对仍获批准的 `face_recognition` 制品；撤销后不允许断网积压绕过审批。

字段样例见 `deploy/model-manifest.example.json` 与 `deploy/triton-model-config.example.pbtxt`。示例摘要占位符必须替换为导出后实际计算的 64 位小写十六进制值，manifest、Triton 配置和中心制品记录三处完全相同。

## 4. 开源引入门槛

正式采用候选仓库前必须固定 tag/commit、保存许可证文本哈希、完成 SBOM/SCA/CVE 扫描，并在目标 GPU 和现场验收集上保存可复现实验。公开 InsightFace 权重不自动视为可商用；Ultralytics AGPL 组件不作为闭源生产默认方案。代码许可证和模型权重许可证分别审批。

## 5. 发布与回滚

1. 登记制品和离线指标，由另一名管理员审批。
2. 在普通区域单节点影子运行，事件不触发外部联动。
3. 比较 recall、误报、P95/P99、GPU/显存与队列峰值。
4. 分批扩大节点范围；每批保留上一摘要的不可变制品。
5. 回滚通过恢复上一已批准 manifest 并重启节点完成，禁止覆盖原版本文件。

模型文件、现场数据、摄像头凭据和人脸样本均不进入源码仓库。

SB3/PyTorch 等研究制品在解析时可能触发反序列化逻辑，必须按可执行输入处理。RL 候选评估以单次受限读取冻结候选字节、在同一次读取中匹配独立批准清单的 SHA-256，并只加载这份已认证内存快照，避免路径在校验与反序列化之间被替换。即便摘要匹配，也只能在无生产凭据、无生产网络出口、只读模型挂载和一次性文件系统的隔离执行器加载；不能把“文件摘要已记录”误当成发布者身份或安全扫描证明。
