- 人脸 Provider 合约新增模型 SHA-256，并与版本共同绑定 AES-GCM 附加数据、模板检索、生产审批和事件元数据；`0011` 迁移对无法证明制品身份的旧模板失败关闭，离线结构化事件入库时再次校验审批，制品撤销不能被断网积压绕过。
- edge 心跳新增严格有界的摄像头故障代码集合，中心保留所有并发故障原因，操作台在节点卡片中显示原因而非只有模糊的 `degraded`；自由文本和超出合同的错误被拒绝，避免凭据或异常详情进入中心遥测。
- 生产配置现在强制人脸 Provider 与通知网关使用 HTTPS，并为人脸请求超时、图像大小、质量、活体和匹配阈值增加启动期有限边界；Compose 显式暴露这些参数，错误配置不会静默形成全匹配、全拒绝或无界资源消耗。
- edge 模型 manifest 改为严格 JSON 类型合同，不再把数字/对象强制转换为身份、路径或尺寸；Triton 单帧检测输出增加 100,000 行硬上限，畸形模型配置和资源放大响应均失败关闭。
- MediaMTX 周期对账补齐删除阶段：专用实例中已不属于任何摄像头的显式拉流路径会移除，保留 `all_others` 和暂时无法解密的摄像头路径；删除计数进入 worker 心跳，避免点位删除后长期残留 RTSP 凭据与内部路径。
- MediaMTX 删除阶段进一步收紧所有权边界：只删除符合平台摄像头命名合同的陈旧路径，保留 `all_others`、外部正则/嵌套路径及暂时无法解密的摄像头路径，避免专用实例发生配置漂移时误删非平台资源。
- 浏览器 API 增加会话级 `AbortController`：注销、401 会话失效或身份切换会立即取消旧会话的在途 HTTP、离线 `online` 等待和退避定时器；请求世代继续阻止同一会话内迟到分页响应覆盖新筛选结果，长时间断网不再累积已失效身份的监听器。
- `0011` 人脸制品身份迁移新增升级/回滚安全回归：旧模板密文保留但强制停用、人员登记标志清除、制品摘要索引创建；回滚字段后也不得重新激活无法证明制品来源的历史模板。
- edge 摄像头并发故障在 UI 详情之外新增低基数 Prometheus 聚合与区域范围大盘告警：分别统计当前降级报告数和故障码总数，不把摄像头、节点或错误文本放入指标标签，少量子链路故障不再依赖 80% 总体可用率才暴露。
- 通知网关契约新增直接回归证据：请求固定携带数据库幂等键、服务认证、最小通道载荷并禁止重定向；dispatcher 进程状态丢失后仍按 PostgreSQL 中的失败状态、尝试次数和到期时间继续投递。
- 通知生命周期改为成功送达后才开始 90 天留存计时；长断网积压即使创建时间很早，恢复后刚送达的投递与其事件引用也会继续保留完整周期，只有历史异常记录缺少 `sent_at` 时才兼容回退创建时间。
- 告警冷却从固定时间桶改为按规则、摄像头、事件类型和通道计算的真实滚动窗口；PostgreSQL 通过规则共享锁与作用域事务 advisory lock 防止并发双发，`0` 秒不再误抑制同秒的不同事件，事件级幂等键仍阻止重复处理同一事件。
- 中心 worker 增加基于真实子任务进展的进程内停滞看门狗：通知、快照法律保留和 MediaMTX 每完成一项有界工作即续期，超过心跳阈值完全无进展则退出并由 Compose 自动拉起；普通数据库/网络断线的既有退避循环会持续续期，不会误形成重启风暴。
- PostgreSQL 加密备份在创建 dump 前新增磁盘失败关闭预检：清理已异地交接且过期的本地组后，要求可用空间至少为当前数据库大小三倍加默认 1 GiB 保留量；空间恢复后 systemd 继续自动重试，未上传制品仍不为腾空间而删除。
- `0011` 人脸制品身份迁移的降级路径进一步失败关闭：删除模型摘要列前停用包括升级后新登记项在内的全部模板并清除人员登记标志，防止旧版代码把无法按原 AAD 解密的新密文误当作有效模板。
- `0012` 为滚动告警冷却增加事件作用域与投递作用域复合索引，避免按规则、摄像头、事件类型、通道和时间范围判定时随 90 天历史表线性放大；结构迁移测试同步核对两端索引与 head revision。
- edge 增加逐摄像头原生调用停滞看门狗：帧处理、重连状态和预期 outbox 背压都会刷新进展，单路 RTSP open/read、推理或文件调用完全卡死超过默认 60 秒时进程退出并由 Compose 重建；正常断网退避不会触发重启风暴。
- RL 五种子研究运行器改为可持久续跑：完整 seed 通过请求/模型/指标摘要重新验证后跳过，当前 seed 以模型先提交、元数据后提交的原子 PPO 检查点恢复，绑定训练 trace、源码身份和 SB3 实际步数；损坏、残缺和孤立临时制品分区归档。带时区 deadline 时子进程失败最高 300 秒退避重试，到期终止并以退出码 75 保留状态；研究清单仍强制 `not_selected`。
- RL 新增纯标准库研究监督器：advisory lock 防止重复实例，持久状态绑定 seed/步数/deadline，runner 异常退出后最高 300 秒退避重启，配置错误立即失败；deadline 到达后给内部检查点提交 45 秒宽限，仍未退出则终止整个进程树。study runner 自身也在 heartbeat/文件系统等异常展开时回收训练子进程，避免监督重启后旧训练与新训练并行写同一 seed。
